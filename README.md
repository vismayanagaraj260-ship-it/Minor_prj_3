# RedFlag – The Fraud Files

## About the Project

RedFlag – The Fraud Files is a SQL-based minor project focused on identifying suspicious transaction patterns using MySQL.

The project uses a transaction dataset and applies different SQL queries to detect possible fraudulent activities.

## Tools Used

- MySQL
- MySQL Workbench
- SQL

## Fraud Patterns Detected

The project analyzes 12 different patterns:

1. Velocity Fraud
2. Round-Amount Clustering
3. Card Testing
4. Failed-Then-Succeeded Transactions
5. Odd-Hour Concentration
6. Mule Accounts
7. Refund Abuse
8. Merchant Collusion
9. Just-Under-Threshold Transactions
10. Dormant-Then-Active Accounts
11. Velocity Spike
12. Geographic Impossibility

## SQL Concepts Used

- SELECT
- WHERE
- GROUP BY
- HAVING
- CASE
- JOIN
- CTEs
- Aggregate Functions
- Window Functions
- LAG()
- ROW_NUMBER()
- DATE and TIME Functions

## Project Objective

The main objective of this project is to use SQL to analyze transaction data and identify patterns that may indicate fraudulent or suspicious activity.
